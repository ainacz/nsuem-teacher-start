# Старт преподавателя НГУЭУ

Демонстрационный путеводитель нового преподавателя: десять шагов адаптации, подробная памятка из 36 тем в восьми разделах, девять рабочих сервисов, поиск по задачам и помощь.

[Открыть прототип](https://ainacz.github.io/nsuem-teacher-start/)

Личные отметки сохраняются только в браузере. Путеводитель не выдаёт доступы и не подтверждает кадровые процедуры или прохождение инструктажей. Маршрут предлагается для обсуждения и согласования с университетом.

Оформление: [официальный фирменный стиль НГУЭУ](https://nsuem.ru/smi/style.php), русский логотип, TT Runs для заголовков, Verdana для основного текста. Содержание основано на памятке новому работнику и открытых официальных ресурсах, просмотренных 28–29 октября 2026 года.

Сайт работает на HTML, CSS и JavaScript без сборки. Публикация — GitHub Pages из ветки `main`.

В подробной памятке отделены сведения бумажного издания, опубликованного сайта и документа. У каждой темы есть статус, дата сопоставления, источники и ограничения проверки. Фотографии исходного издания доступны в разделе источников. Ни дата сопоставления, ни ссылка на сайт не означают утверждение путеводителя университетом или назначение льготы конкретному человеку.
